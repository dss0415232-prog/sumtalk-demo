# 숲톡 민원AI (시연용 홈페이지)

국립산림치유원 AI 민원·상담 서비스 시제품의 **브라우저 실행 버전**입니다. 서버 없이 이 페이지를 열면 브라우저 안에서 같은 대화 엔진이 실행됩니다.

- 국민용 화면: `index.html` (이 저장소의 GitHub Pages 주소로 접속)
- 관리자 화면: `admin.html` (시연 비밀번호 `demo1234`, 모의 로그만 표시)
- 발표자료: `deck.html` · 비교: `compare.html`

## 알아둘 점
- 시연용입니다. 요금·FAQ 등은 공개 안내자료와 모의데이터이며 **예약 가능 여부를 확정하지 않습니다.**
- 처음 열 때 브라우저용 Python 실행기(약 14MB)를 내려받아 10~20초 걸릴 수 있습니다. 최신 Chrome·Edge를 권장합니다.
- 접수·승인·대화 기록은 이 브라우저 메모리에만 있고 새로고침하면 처음 상태로 돌아갑니다.
- 이메일은 실제로 발송되지 않고 관리자 화면 「발송함」에만 기록됩니다. 외부 LLM은 연결되어 있지 않습니다(주변 관광 추천 제외 전 기능 동작).
- 원본 소스(Python 서버 버전)는 공공 GitLab 제출물을 참고하세요.
